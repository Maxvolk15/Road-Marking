# Project: Road-Marking

## Тема проекта
Контроль дорожной разметки: загрузка фотографий улиц, обнаружение стёртых линий и пробелов, формирование заданий на ремонт.


## Назначение приложения
Приложение предназначено для контроля состояния дорожной разметки. Пользователи смогут загружать фотографии дорог, система будет анализировать их на предмет наличия стёртых линий и пробелов в разметке. На основе анализа формируются задания на ремонт для соответствующих служб. 

## Основные пользовательские сценарии
1. **Просмотр статистики (Dashboard):** Пользователь заходит в систему и видит общее количество загруженных фотографий, количество обработанных снимков и количество открытых задач на ремонт.
2. **Загрузка фотографий (Upload):** Пользователь переходит на экран загрузки, выбирает файл с фотографией улицы, записывает адрес, после чего нажимает кнопку загрузки (имитация).
3. **Просмотр результатов анализа:** Пользователь просматривает список всех фото, их статусы ("Обработано", "В обработке", "Ошибка") и количество обнаруженных дефектов. При клике на фото открывается его детализация.
4. **Просмотр заданий на ремонт:** Пользователь может видеть список всех сгенерированных заданий, привязанных к конкретным фото, с указанием их статуса ("Открыто", "В работе", "Выполнено").

## Реализованные экраны
1. **Главная страница (Dashboard)** - общая статистика системы.
2. **Загрузка (Upload)** - интерфейс для выбора и загрузки изображения.
3. **Анализ (Analysis)** - карточки с фотографиями и их статусом.
4. **Детали фото (Analysis Detail)** - просмотр конкретной фотографии и привязанных к ней заданий на ремонт.
5. **Задания на ремонт (Tasks)** - таблица со списком заданий и их статусами.

## Технологический стек
- **Frontend-фреймворк:** React
- **Язык:** TypeScript
- **Сборщик:** Vite
- **UI-библиотека:** Material-UI (MUI) @mui/material
- **Маршрутизация:** react-router-dom

## Структура frontend-проекта
```text
frontend/
├── index.html           # Главный HTML-файл
├── package.json         # Зависимости и скрипты
├── vite.config.ts       # Конфигурация Vite
├── tsconfig.json        # Конфигурация TypeScript
└── src/
    ├── main.tsx         # Точка входа React
    ├── App.tsx          # Настройка маршрутизации (Routes)
    ├── mocks/
    │   └── data.ts      # Демонстрационные (mock) данные
    ├── components/
    │   └── Layout.tsx   # Общий каркас с боковой панелью навигации (Sidebar)
    └── pages/           # Страницы приложения (экраны)
        ├── Dashboard.tsx
        ├── Upload.tsx
        ├── Analysis.tsx
        ├── AnalysisDetail.tsx
        └── Tasks.tsx
```

## Как установить зависимости
Убедитесь, что у вас установлен **Node.js** (рекомендуется версия 18+).
1. Перейдите в папку `frontend`:
2. Установите зависимости:
   ```bash
   npm install
   ```

## Как запустить проект
Находясь в папке `frontend`, выполните команду:
```bash
npm run dev
```
После этого проект будет доступен в браузере по адресу `http://localhost:5173`.

## Как проверить работу навигации
1. Откройте приложение в браузере. Вы попадёте на Главную страницу (Дашборд).
2. Используйте левое боковое меню (на мобильных устройствах — меню-гамбургер) для перехода между разделами "Загрузка фото", "Анализ" и "Задания на ремонт".
3. На странице "Анализ" нажмите кнопку "Подробнее" на карточке фото, чтобы проверить переход на детальную страницу `/analysis/:id`.
4. Воспользуйтесь кнопкой "Назад к списку" на детальной странице.

## Демонстрационные (mock) данные
Вся информация в приложении на данный момент является демонстрационной (`src/mocks/data.ts`). 
Используются статические массивы `mockPhotos` и `mockTasks`, так как backend-составляющая ещё не разработана. Изображения подтягиваются с различных баз.

## Функции-заглушки
- Кнопка "Загрузить для анализа" на странице Upload лишь имитирует загрузку (показывает alert).
